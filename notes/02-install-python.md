# 02. 安装 Python

## 一、知识点

安装解释器、验证环境、运行程序。

## 二、专业术语

- Installer —— 安装程序
- PATH —— 命令搜索路径
- Terminal —— 终端

## 三、语法

```python
python --version
```

## 四、示例代码

```python
python --version
```

## 五、注意事项

- Windows 上命令可能是 `python`，macOS/Linux 常见为 `python3`。
- 终端能显示版本号才说明环境基本可用。

## 六、常用函数/方法

### `python3 hello.py`

作用：运行 Python 文件

```python
python3 hello.py
```

## 七、我的理解

> 安装完成并能在终端看到版本号，才说明环境可用。
