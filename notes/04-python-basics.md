# 04. Python 基础

## 一、知识点

变量、数据类型、运算符、布尔值。

## 二、专业术语

- Variable —— 变量
- Data Type —— 数据类型
- Assignment —— 赋值
- Boolean —— 布尔值

## 三、语法

```python
age = 18
name = "Ada"
is_passed = True
```

## 四、示例代码

```python
age = 18
name = "Ada"
is_passed = True
```

## 五、注意事项

- `=` 是赋值，`==` 才是比较。
- 变量名不能以数字开头，且区分大小写。
- `True` 和 `False` 首字母必须大写。

## 六、常用函数/方法

### `type()`

作用：查看数据类型

```python
type(123)
```
### `int()`

作用：转换为整数

```python
int("12")
```

## 七、我的理解

> 变量是给数据起名字，数据类型决定它可以进行哪些操作。
