# 03. 第一个 Python 程序

## 一、知识点

源代码、运行、输出、注释。

## 二、专业术语

- Source Code —— 源代码
- Statement —— 语句
- Comment —— 注释

## 三、语法

```python
print("Hello, world!")
# 这一行是注释
```

## 四、示例代码

```python
print("Hello, world!")
# 这一行是注释
```

## 五、注意事项

- 字符串要使用引号包裹。
- Python 对缩进敏感，通常统一使用 4 个空格。

## 六、常用函数/方法

### `print()`

作用：输出内容

```python
print("Hello", "Python")
```
