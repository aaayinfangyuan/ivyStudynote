# 11. 函数进阶

## 一、知识点

默认参数、可变参数、关键字参数。

## 二、专业术语

- Default Parameter —— 默认参数
- Variable Argument —— 可变参数
- Keyword Argument —— 关键字参数

## 三、语法

```python
def power(x, n=2):
    return x ** n
```

## 四、示例代码

```python
def power(x, n=2):
    return x ** n
```

## 五、注意事项

- 默认参数应尽量使用不可变对象。
- 可变参数会把多个值组成 tuple。
