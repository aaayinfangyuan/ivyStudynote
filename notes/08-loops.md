# 08. 循环

## 一、知识点

for、while、迭代、break。

## 二、专业术语

- Loop —— 循环
- Iteration —— 迭代
- Range —— 范围
- Break —— 中断

## 三、语法

```python
for n in range(1, 101):
    print(n)
```

## 四、示例代码

```python
for n in range(1, 101):
    print(n)
```

## 五、注意事项

- `range(1, 101)` 不包含 101。
- while 循环要注意避免死循环。
- break 会结束当前循环。

## 六、常用函数/方法

### `range()`

作用：生成整数序列

```python
range(1, 5)
```
### `enumerate()`

作用：同时取得索引和值

```python
enumerate(names)
```

## 七、我的理解

> 循环适合处理重复任务。
