# 07. 条件判断

## 一、知识点

条件、分支、缩进、比较运算。

## 二、专业术语

- Condition —— 条件
- Branch —— 分支
- Indentation —— 缩进

## 三、语法

```python
if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

## 四、示例代码

```python
if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

## 五、注意事项

- 条件语句末尾要有英文冒号。
- 同一代码块必须保持一致缩进。
- elif 可以有多个，else 可以省略。
