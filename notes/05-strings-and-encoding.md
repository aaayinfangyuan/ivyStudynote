# 05. 字符串和编码

## 一、知识点

字符串、编码、格式化、转义字符。

## 二、专业术语

- String —— 字符串
- Encoding —— 编码
- Unicode —— 统一字符编码
- Format —— 格式化

## 三、语法

```python
name = "小明"
score = 95
print(f"{name} 的成绩是 {score}")
```

## 四、示例代码

```python
name = "小明"
score = 95
print(f"{name} 的成绩是 {score}")
```

## 五、注意事项

- 字符串不能直接修改某个字符。
- f-string 中花括号内可以放变量或表达式。

## 六、常用函数/方法

### `len()`

作用：获取字符串长度

```python
len("Python")
```
### `str()`

作用：转换为字符串

```python
str(100)
```

## 七、我的理解

> 字符串是一串文本，格式化能把变量自然地放入文本中。
