# 12. 模块

## 一、知识点

导入、标准库、命名空间。

## 二、专业术语

- Module —— 模块
- Import —— 导入
- Standard Library —— 标准库

## 三、语法

```python
import math
print(math.sqrt(9))
```

## 四、示例代码

```python
import math
print(math.sqrt(9))
```

## 五、注意事项

- 模块名不要与标准库重名。
- 使用 `import module` 时，调用来源更清楚。
